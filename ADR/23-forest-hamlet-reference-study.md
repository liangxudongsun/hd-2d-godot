# ADR-23 · 林间小村参考效果范例

状态：采用实现架构；用户美术审阅独立待定。

## 背景

用户希望把视频 BV1TFjz6eEK7 中的精致微缩环境转成现有工程中可行走的场景，并沿用月饰少女和 AW／VGP。

## 决定

独立添加 forest_hamlet 场景，复用现有角色与 Forward+。木屋、树冠、石头与道具由确定性 Blender 源生成真实几何；建筑墙、屋檐和石岸不能用视频截图做单张背景。地表用世界坐标连续混合草／土，边界噪声量化到像素密度；水面原生受光加解析波纹；叶片模型的风动与地面碰撞分离。

原创 imagegen 四材质母版通过 AW 加工，保存精确输入哈希和配方。颜色图不用于自动推断角色法线。地面的轻微法线来自明确的解析微结构信号，其目的为可调效果研究，不声称恢复参考视频的真实表面。

VGP 保存候选与阶段材料。渲染测试只证明工程行为；不替用户签署视觉批准，不将未审阅候选登记为已批准正式资产。

## 取舍

能展示真实遮挡、动态光照、镜头移动和像素材质。参考是 AI 概念预告，跨帧形状与细节不能作为同一稳定三维几何的精确测量。范例重现视觉特征，不宣称逐像素一致、复现原作资产或包含室内与战斗玩法。


## 修订 · 像素密度、角色 billboard 与参考构图

2026-10-22 的用户反馈要求更明确的 HD-2D 像素材质、正常角色比例、相机靠近，并以补充的村落截图确定构图。

材质从初版 256×256 改为 64×64，共享 64 色来源色板，AW 使用新的 `forest-hamlet-20261022-pixel-r2` 身份。世界坐标取样以 16 texel/m 统一草土、木屋和道具密度，避免每片屋瓦或每块小石重新铺满一整张高密度贴图；颜色簇和粗糙表面与真实三维光照并存。保留原母图、旧配方、旧 AW/VGP 记录与确定性几何种子。

角色的 Sprite3D 自定义 shader 会覆盖内置 billboard 行为，因此在共用 include 中增加默认关闭的 `camera_facing_billboard`。森林适配器显式启用，使用 `MAIN_CAM_INV_VIEW_MATRIX` 构造完整朝向，保留模型轴长并更新法线矩阵，保持阴影 pass 与主相机一致。原四方向动画、脚底枢轴和源像素不变；GPU 在多俯角、侧转及缩放下读回真实轮廓检验。

最终相机以原角色世界尺寸为约束，使用 `(0,12,17.5)` 偏移、39° FOV 和固定高度的平滑跟随焦点。相比初版距离缩短约 20%，完整动画轮廓占画高约 13.6%、脚底约 56.9%H，以保持参考图中左下池塘、中央角色、上方村屋的构图。景深使用角色在相机空间的深度，完整 billboard 位于同一清晰平面。该选择针对补图的空间关系，不把不同角色的头身比或原画模型当作可复制的几何。

## 修订 · r5 完整场景配置与实时效果

用户后续要求景深、辉光、时段及其他既有效果可实时调整并保存恢复。新增纯数据辅助模块 `scripts/forest_hamlet/scene_settings.gd`，统一 20 项数值的范围与默认、9 个效果开关、时段、schema 校验及原子写入；它不直接操作渲染节点。原场景控制器继续拥有相机、WorldEnvironment、云层与全局灯光，先验证完整配置，再把值应用到已有模块。日光／黄昏重设基础灯光时保留用户的数值和开关，景深仍跟随人物相机空间深度。

继续使用 `user://forest-hamlet-clouds.cfg`，保留 `[clouds] schema_version=1`，增加 `[scene] schema_version=2`、`[features]` 和 `[effects]`。旧配置读入时仅在内存补全默认值；已有 0.7 对比和 0.48 密度不量化、不自动写回。点击保存才升级文件；正常启动自动读取，实时预览和测试不写个人偏好。完整读取失败不局部应用，保存失败保留之前文件。

旧场景与云层 API、快照字段及默认效果保持兼容，另提供完整 profile 接口。五个中文分页和全局保存状态用于控制台；旧云页仍为初始页。原角色、模型、贴图、构图与项目默认入口不因调参扩展改变。

新证据使用 `scene-settings` profile 和 `forest-hamlet-20261022-scene-settings-r5-final`，绑定运行指纹及包含验证/工作流代码的完整来源指纹。当前 `assets/**` 必须与 r4 原生快照逐文件一致。AW 原生运行只执行专用无窗口合同，外部 GPU 证据独立生成；VGP 必须作为 r4 的后继候选和审阅轮次，保持 `concept_design / pending_review`，不产生人工批准或阶段准入。旧 r4 记录和更早路线／透光测量保留。操作、范围与出口条件见 [场景参数 r5](../docs/forest-hamlet/scene-settings-r5.md)。
