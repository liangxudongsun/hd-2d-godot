# 不规则全局光照

`scripts/forest_hamlet/global_lighting.gd` 在空间云影之外，独立改变原生太阳和环境补光能量。默认开启；由场景统一调用 `tick(delta)`，不会自行计时。J 键控制此模块，云影、体积雾和 Glow 仍各自独立。

固定种子为 **20261022**。太阳与环境补光使用不同种子偏移的四个 `FastNoiseLite.TYPE_SIMPLEX_SMOOTH` 时间信号，权重为 **0.47 / 0.31 / 0.14 / 0.08**。太阳尺度为 **11.3 / 22.7 / 3.9 / 6.3 秒**，环境补光为 **15.7 / 24.1 / 4.7 / 6.9 秒**；这些是噪声采样尺度，不是重复周期。前两项主导缓慢变化，后两项提供幅度较小的变化，不采用单一固定正弦。

每项减去其零时刻样本，再通过连续的 `x / sqrt(1 + x²)` 压缩，保证 **t=0 的两项倍率精确为 1**，太阳倍率严格处于 **0.82–1.18** 内、环境倍率处于 **0.90–1.10** 内。日光能量基值为 **1.45 / 0.55**，黄昏为 **1.15 / 0.40**（太阳 / 环境）。这是幅度上界，不表示每次变化都达到该边界。

模块已在真实 Godot 中解析并采样。本次固定种子 **0–90 秒**窗口内，太阳倍率约 **0.9161–1.1210**，57 秒最弱、84 秒最强；环境倍率约 **0.9441–1.0688**，t=0 两者均为 1。上述范围来自 **1 秒间隔**的有限窗口采样，不代表无限运行的全局极值。

`set_time(t)` 会立即写入实际能量，便于冻结到同一时刻做 GPU 对照；`set_enabled(false)` 立即恢复当前昼夜基值；`set_motion_enabled(false)` 后 `tick` 保持时钟与能量，显式 `set_time` 仍可用于选择测试时刻。重新启用沿用当前时钟，切换昼夜保持同一组倍率。关闭效果时内部时钟仍可随场景推进；场景冻结或关闭 motion 则停止推进。

模块只写 `DirectionalLight3D.light_energy` 和 `Environment.ambient_light_energy`，不会改变曝光、原图颜色、云遮罩、太阳方向、雾参数、镜头或角色。云影比较应把本模块固定为 t=0；全局光变比较应关闭云影，冻结其他动画，在固定相机下采集强光、弱光和关闭三图。法线方向隔离探针关闭本模块，避免混入整体能量差。`snapshot()` 提供时钟、种子、基值、倍率、实际能量及全部噪声尺度，最终验收以实际引擎采样和 GPU 像素对照为准。

## 本轮实际验证

[r2 修订](revisions/atmosphere-r2-20261022/README.md) 的 **15 项资源、47 项运行、26 项 GPU、65 项像素检查全部通过**。真实引擎检查覆盖 t=0 中性基线、倍率边界、实际原生能量同步、固定时刻重现、日暮切换不累乘、关闭恢复、独立时钟及冻结。完整捕获包含 15 张 PNG，角色真实路线完成 6/6 路点，用时 22.45 秒。

全局变化的 [弱光](revisions/atmosphere-r2-20261022/close-day-global-weak.png)、[强光](revisions/atmosphere-r2-20261022/close-day-global-strong.png)、[关闭](revisions/atmosphere-r2-20261022/close-day-global-off.png) 三图均关闭云遮挡并保持其他条件一致。强 / 弱图的平均绝对 RGB 差为约 **8.727**，约 **91.93%** 像素超过 2 级变化阈值；地面、房屋、植被三个区域均有变化。关闭后相对 t=0 中性基线的平均差约 **0.081**，超过阈值的像素为 0，说明关闭恢复在本次 GPU 比较容差内成立，不能将其表述为 PNG 逐字节相同。

本模块作用于原生受光的场景物体及相关散射。远景雪山仍采用显式法线重光照的 `unshaded` 材质，只接收太阳方向、颜色与昼夜设置，不直接乘这两项原生能量，因此没有声称远景原画也跟随相同倍率变化。
